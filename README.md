# Knowledge Graph for Analyzing Housing Prices and Accessibility in Vienna

This project explores how a small Knowledge Graph can be used to analyze housing prices and accessibility in Vienna. The main goal is to connect information about districts, housing prices, public transport access, and nearby services so that relationships between location, affordability, and accessibility can be studied in a structured way.

## Planned Datasets

The project is planned to use public or openly available datasets related to:

- Housing prices or rent levels in Vienna
- Vienna districts and administrative areas
- Public transport stops, stations, or accessibility indicators
- Points of interest such as schools, parks, shops, or healthcare facilities

The raw datasets will be stored in `data/raw/`, and cleaned or transformed files will be stored in `data/processed/`.

## Tools Used

The project will use a simple Python-based workflow:

- Python for data processing and project logic
- Pandas for loading, cleaning, and transforming tabular data
- NetworkX for creating and analyzing the Knowledge Graph
- Matplotlib for visualizing graph structures and results
